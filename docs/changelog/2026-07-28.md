# 2026-07-28 开发日志

## Bug 修复

### CA 站点价格抓不到
- **原因**：`renderer/sites/ca/selectors.js` 覆盖了 `_base` 的所有 fallback，部分 ASIN 的价格元素在 `#corePrice_feature_div` 而非 `.a-price[data-a-size="xl"]`
- **修复**：`ca/selectors.js` price 数组补充 `#corePrice_feature_div .a-offscreen`

### 父体 ASIN 全部返回 N/A
- **原因**：`_base/selectors.js` 中 `parentAsin` 的 regex 选择器用的是 RegExp 字面量，`JSON.stringify` 无法序列化 RegExp，注入页面后变成 `null`，导致所有 regex 匹配失效
- **修复**：将 `{ type: 'regex', regex: /.../ }` 改为 `{ type: 'regex', pattern: '...' }`（字符串），`_base/scraper.js` 的 `queryWithFallback` 改用 `new RegExp(sel.pattern)` 动态构建

### Amazon 拦截页（Continue shopping）导致批量抓取失败
- **原因**：Amazon 对无 Cookie 的新 BrowserWindow 访问会插入确认拦截页，页面加载完成后由客户端脚本渲染，`waitForLoad` 之后检测已经太晚
- **修复**：将检测逻辑移至 `injectAndScrape` 内（scraper 稳定等待之后），使用结构检测（无商品元素 + 页面文本 < 600 字符）而非文本匹配，覆盖所有语言站点；检测到后自动点击继续按钮并重新等待页面加载；日志记录点击按钮文本，便于排查

## 新工具：选择器调试器

**背景**：新增抓取字段时需要手动在 DevTools 找选择器，多站点差异繁琐且正确率不高，需要一个专业的元素识别工具辅助开发。

**文件**：
- `renderer/debugger/panel.js` — 注入到 Amazon 页面的自包含调试面板
- `electron/selector-debugger.js` — 主进程窗口管理

**功能**：
- 设置页新增入口，选站点 + 可选 ASIN，点击打开真实 Amazon 页面
- 注入右侧固定调试面板（360px），`body` 自动腾出对应右边距，不遮挡页面
- **拾取 Tab**：点击「拾取」进入拾取模式，鼠标悬停橙色虚线高亮，点击元素自动生成多个候选选择器并按稳定性 ★ 排序（ID > Amazon 数据属性 > 祖先ID+后代 > 语义类 > CSS路径），同时展示 textContent / innerText / a-offscreen / attr 四种提取值，支持一键复制
- **实时测试 Tab**：输入任意 CSS 选择器，实时显示命中数量（唯一✓/多个⚠/大量❌）和值列表，在页面上蓝色高亮命中元素
- 面板可折叠，收起后右侧露出蓝色竖排触发条点击展开
- ESC 键：拾取模式中取消拾取；面板收起时展开面板
- **主题跟随**：打开调试器时传入当前主题（light/dark），面板配色与主应用一致
