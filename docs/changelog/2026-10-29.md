# 2026-10-29 开发日志

## 全站点产品详情 ASIN 不一致告警

- 实测访问 `https://www.amazon.com/dp/B0FVXZR93K?language=en_US`，URL 保持原 ASIN，但 `#detailBullets_feature_div li` 的 ASIN 行显示 `B088D1Y5RY`。直接访问后者时详情 ASIN 与目标一致。
- 详情 ASIN 解析放入 `_base/parsers.js`，所有站点共用身份判断，产品详情提取仍沿用各站点实现。仅明确有效的 ASIN 不一致时，按现有下架失败处理；即使关闭产品信息和 BSR 字段仍执行校验。
- 告警文案：`商品已下架：目标 ASIN B0FVXZR93K 的产品详情显示为 ASIN B088D1Y5RY`。
- 结果及历史中保留详情、目标 ASIN、详情 ASIN、URL 和观测时间。该记录描述页面观测，不替代 Amazon 对下架原因的确认。
- 原有 URL 重定向检测保留；未读到详情 ASIN 时不因缺失误报。
- 验证：`node --test tests/asin-identity.test.js`，覆盖 20 个内置站点及自定义站点的生成脚本，检查详情不一致、匹配/缺失/无效值，并覆盖父体排除、字段开关、原有跳转、通知内容及历史证据。真实页面复现证据来自美国站，其他站点本次使用构造详情数据回归验证。
